# app · 한입씩 프로토타입

폰에서 눌러 볼 수 있는 확인용 웹 프로토타입. 실제 서비스 코드가 아니다.

- 보기: https://claude.ai/artifact/PGvm8N2CDemxqGKdVdJa43 (비공개 링크)
- 화면: 홈(시기별 알림, 오늘 추천), 레시피 목록·상세, 재료 사전·상세(대상별 탭), 냉장고 재료로 찾기, 온 가족 레시피, 알레르기 식품 시작하기, 이럴 땐 이렇게, 우리 아이, 온보딩
- 데이터: `data/`는 `node scripts/build-data.mjs`가 만든다 (검수본 레시피, 식재료 가이드, 위험 재료, 상황별 초안). 직접 고치지 않는다.
- 빠진 것: 카카오 로그인, 서버 저장, 내 레시피 올리기, 식단표(감수 전이라 준비 중 화면). 아이 정보는 그 브라우저에만 저장된다.
- 알레르기 화면은 `docs/hanip_allergy_policy_draft.md`의 기관 문장 범위 안에서만 안내하고, 일차별 양이나 며칠 프로그램은 넣지 않는다.

## 수정 후 다시 올리기

`index.html`은 Artifact 형식이라 `<!doctype>`, `<head>`, `<body>` 없이 시작한다. 파일 탐색기에서 바로 열면 데이터를 불러오지 못하므로, 로컬에서 볼 때는 `app` 폴더에서 `npx serve`처럼 간단한 서버로 연다.
