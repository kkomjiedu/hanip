## 0. 처리 결과 (2026-10-18 사용자 결정 반영)

아래 3장의 문제는 원본 대신 `data/recipes/hanip_recipe_corrections.json` 규칙으로 고쳐 검수본 `data/recipes/hanip_recipes_reviewed.json`에 반영했다. 빌드 검사기는 원본에서 오류 184건(가능성 알레르기 누락 91, 같이한입 빈 월령 50, 잘못 뽑힌 재료 27, 알레르기 누락 7, 빠진 재료 4, 빈 재료 2, 월령 금지 재료 3)을 찾고, 검수본은 0건이다.

| 결정 | 처리 |
| --- | --- |
| 1. 알레르기 누락 전부 고치기 | 제목으로 확실한 것(북어→생선, 크림→우유, 된장·간장·장조림→대두)은 `allergens`에 추가. 제목에 없는 부재료(전·완자·팬케이크·머핀의 밀·달걀·우유, 조림의 간장, 리소토·그라탱·카레의 유제품·밀, 북엇국의 달걀)는 `possible_allergens`로 추가해 필터에서 제외되게 함. 52개 레시피 |
| 2. 잘못 뽑힌 재료 고치고 재발 막기 | 양배추·배추·무침·김치·오트밀·고구마 줄기·미역줄기 오류 수정, 뭇국의 무·닭곰탕·북엇국 재료 추가. 같은 오류가 들어오면 빌드가 실패하도록 검사 추가. 오트밀의 밀 알레르기 표시는 혼입 가능성 때문에 유지 |
| 3. 같이한입은 60개월 이상 | 50개 `min_months` null → 60 |
| 4. 주의 넣기 | 위험 재료 파일(22종)과 모양 규칙에서 143개 레시피에 보호자 주의 자동 부착 (땅콩 형태, 완두콩 으깨기, 김·미역 무염 소량, 주먹밥·완자 크기 등) |
| 5. 꿀 등 위험 재료 설명 | `data/ingredients/hanip_risk_ingredients.json`, `docs/hanip_risk_ingredients.md`. 꿀은 공식 출처 기준 12개월 미만 금지 + 4세 이하 첨가당으로 피하기 |

| 6. `채소`라고만 쓴 16개 | AI가 카탈로그에 이미 쓰인 같은 단계 이하 채소로 제안, 사용자 승인 후 `vegetable_specifications`로 추가. 새 알레르기 없음 |

남은 일: `possible_allergens`는 실제 레시피를 넣을 때 확정해야 한다.

## 4. 식재료 가이드와 레시피 재료 이름 비교

- 레시피에는 있으나 식재료 가이드에 없는 재료 20개: 가지, 들깨, 렌틸, 메추리알, 무, 배추, 비트, 숙주, 아스파라거스, 양배추, 양파, 연근, 오이, 완두콩, 카레, 콜리플라워, 콩나물, 퀴노아, 파스타, 흰살생선. (무·배추·배 일부는 3-2의 잘못 뽑힌 값)
- 가이드에는 있으나 레시피에 쓰이지 않은 재료: 아보카도, 딸기, 그리고 "우유/요거트" 중 우유
- 이름 표기 차이: 재료는 `달걀`, 알레르기 값은 `계란`. 가이드는 `우유/요거트`, `김/미역`처럼 두 재료를 한 줄에 묶음. 앱 연동 시 이름 맞춤표가 필요하다 (`data/README.md`).
- `카레`, `파스타`는 단일 식재료가 아니라 가공식품이라 알레르기 성분이 제품마다 다르다.

## 5. 기존 초안 파일의 문제 (AI가 만든 것)

- `content/allergy_days.csv`(달걀 9일·땅콩 7일 일차별 양), `content/allergy_programs.csv`의 기간·시작 시기, 캔버스 A2 화면, 기획서의 알러지 테스트 표는 **출처 없이 만든 수치**다. 새 알레르기 정책 초안의 원칙(기관이 제시하지 않은 일정·양을 만들지 않음)과 맞지 않으므로 지우거나 바꾸어야 한다. 사용자 확인 후 처리한다.
- `content/ingredients.csv`(19개)는 이번 식재료 가이드(30종)와 내용이 겹친다. 가이드를 기준으로 삼을지 정해야 한다.
